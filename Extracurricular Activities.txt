Module 4 — Extracurricular Activities
Manages extracurricular activity entries. Unlimited activities allowed. Scoring uses depth-first model with diminishing
returns on top 10. hours_per_week is accepted and stored internally but NEVER returned in any student-facing
response.
4.1 List Extracurricular Activities
GET /students/me/extracurriculars
Middleware: rateLimiter → verifyJWT → requireRole(student) → auditLogger
Auth: Bearer JWT | Rate Limit: 120 per user per minute
Parameter Type Required Description
limit integer Optional Max items per page. Default 50, max 100.
cursor string Optional Pagination cursor from previous response
Success Response — 200 OK

4.3 Get Single Extracurricular Activity
GET /students/me/extracurriculars/:ec_id
Returns full details for one extracurricular activity owned by the student. Used to populate edit form.
Middleware: rateLimiter → verifyJWT → requireRole(student) → auditLogger
Auth: Bearer JWT | Rate Limit: 120 per user per minute
Parameter Type Description
ec_id integer Extracurricular activity ID
HTTP Status Error Code Cause
404 NOT_FOUND Activity does not exist or belongs to another student
401 TOKEN_INVALID JWT missing, expired, or malformed
429 RATE_LIMIT_EXCEEDED Too many requests
4.4 Update Extracurricular Activity
PUT /students/me/extracurriculars/:ec_id
Full update of an existing activity. Send only fields to change. Triggers async score recalculation.
Middleware: rateLimiter → verifyJWT → requireRole(student) → auditLogger → scoreRecalc | Audit:
profile_update
Auth: Bearer JWT | Rate Limit: 30 per user per minute
Parameter Type Description
ec_id integer Extracurricular activity ID to update
Request body: same optional fields as POST — activity_name, activity_type, years_involved, involvement_level,
hours_per_week, impact_level, description, impact_statement, and all toggle fields. All optional.
HTTP Status Error Code Cause
400 VALIDATION_ERROR Invalid field value
401 TOKEN_INVALID JWT missing, expired, or malformed
404 NOT_FOUND Activity does not exist or belongs to another student
429 RATE_LIMIT_EXCEEDED Too many requests
4.5 Delete Extracurricular Activity
DELETE /students/me/extracurriculars/:ec_id
Permanently deletes an activity. Triggers async score recalculation. Cannot be undone.
Middleware: rateLimiter → verifyJWT → requireRole(student) → auditLogger → scoreRecalc | Audit:
profile_update
Auth: Bearer JWT | Rate Limit: 30 per user per minute
Parameter Type Description
ec_id integer Extracurricular activity ID to delete
Field Type Description
deleted boolean Always true on success
score_recalc_queued boolean Recalculation status
HTTP Status Error Code Cause
404 NOT_FOUND Activity not found or belongs to another student
401 TOKEN_INVALID JWT error
429 RATE_LIMIT_EXCEEDED Too many requests
4.6 Reorder Extracurricular Activities
PATCH /students/me/extracurriculars/reorder
Updates display_order for multiple activities in one atomic operation. Does NOT trigger score recalculation — order does
not affect scoring.
Middleware: rateLimiter → verifyJWT → requireRole(student) → auditLogger
Auth: Bearer JWT | Rate Limit: 30 per user per minute
Field Type Required Description
order array[object] Required Array of { ec_id: integer, display_order: integer } objects
Field Type Description
reordered boolean true on success
updated_count integer Number of activities reordered
HTTP Status Error Code Cause
400 INVALID_EC_IDS One or more ec_id values do not belong to this student
401 TOKEN_INVALID JWT error
429 RATE_LIMIT_EXCEEDED Too many requests
